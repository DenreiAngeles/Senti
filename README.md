# Senti: The All-In-One Finance Hub

**Senti** is a mobile application designed to transition from basic expense tracking into a proactive financial companion. This project was developed in partial fulfillment of the requirements for **CS 312: Mobile Computing** at **Batangas State University - Alangilan Campus**.

## 🌟 Social Impact & SDGs
The development of Senti is grounded in a commitment to social impact, specifically addressing four key Sustainable Development Goals (SDGs):

* **SDG 4 (Quality Education):** Functions as a practical educational tool delivering personalized tips on budgeting and debt management to students and freelancers.
* **SDG 1 (No Poverty):** Provides tools to help users build emergency funds and track debts, fostering resilience against financial instability.
* **SDG 8 (Decent Work and Economic Growth):** Assists gig economy workers in managing irregular income streams to sustain economic participation.
* **SDG 12 (Responsible Consumption and Production):** Uses visual dashboards to make users hyper-aware of spending patterns and nudge them away from impulse consumerism.

## ✨ Key Features
* **Visual Dashboards:** Hyper-aware spending pattern tracking via visual data representations.
* **Functional Login System:** Secure sign-in authentication using Firebase.
* **Registration & Profile Creation:** Tailored onboarding that captures financial status and primary goals.
* **Debt Ledger:** Specialized tracking for managing money owed to others and money owed to the user.
* **Savings Goals:** Milestone-based saving (e.g., "New Laptop") with progress tracking and fund allocation.
* **Dark Mode:** Full support for a dark theme to improve user experience.

## 🛠️ Tech Stack
* **Framework:** Flutter (Dart).
* **Backend & Authentication:** Firebase.
* **Database:** Cloud Firestore.

## 📂 File Structure

```text
├── widgets/       # Reusable components like 3D buttons and custom cards
├── firebase_options.dart # Firebase configuration
└── main.dart      # Application entry point
```
